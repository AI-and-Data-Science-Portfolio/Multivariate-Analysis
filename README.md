# Multivariate-Analysis

Project Goal:

The aim of this report was to practice typical multivariate analysis methods. The report analysed the 2022 Pobal index of deprivation in Ireland.

Description:

Principal component analysis, multidimensional scaling and classification were applied to the data.

Outputs:

All charts, summaries, tables, etc. can be viewed in [MA Project](docs/MA%20Project.pdf) 

How to Run:
1. Download or clone this repository to your computer.
2. Open RStudio and install the required packages:
   
   ```r
   install.packages(c("caret", "class", "cluster", "dplyr", "factoextra", "flexclust", "gridExtra", "MASS", "plyr", "readr", "reshape2", "tidyverse", "vegan"))
   ```
4. Open [`src/MA Project.R`](src/MA%20Project.R) and run the script from top to bottom.
